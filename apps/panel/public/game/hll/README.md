# Hell Let Loose artwork

Map images, tactical maps, role icons, faction emblems, and rank insignia are Hell Let Loose
game assets (© Team17 / Black Matter), bundled here for this community admin tool the same way
the open-source CRCON project (github.com/MarechJ/hll_rcon_tool) bundles them. Not covered by
this repository's license.

Layout: maps/<family>-<environment>.webp · map-icons/ (same names, thumbnail size) ·
tac-maps/<family>.webp · roles/<role>.png (+_black variants) · teams/<faction>[_colored|_dark].webp ·
ranks/<Rank_Name>.webp
