# Hell Let Loose's RCON client, update 5.03

Two of these files are **Team17's** (© Team17), from the RCON client that shipped with Hell Let
Loose update 5.03. They are not covered by this repository's licence, and are kept unmodified, for
reference:

| File | What it is |
|---|---|
| `commands.xml` | the client's `Commands.xml` |
| `dll-property-names.txt` | the property names in the client's `RconClient.dll`, as `strings` reads them |

The other two were captured while using the client and a game server: `console-session.txt` is
the client's log of one session, and `admin-log-sample.txt` holds two admin-log lines (player names
made up) for their format.

This project's own reading of them is `docs/rcon-503.md`. See also `NOTICE.md`.
